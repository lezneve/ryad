# ryad / що перевірено і що ні

стан на 2026-11-14, ryad 0.1.0 (робоче дерево, без комітів). машина й умови — [measurements.md](measurements.md): windows 11 home 25h2 (26200), один дисплей 150 %, uac вимкнено (`EnableLUA = 0`), тож процеси, і ryad теж, мають повний токен адміністратора.

## як перевіряли

автоматичні сценарії запускають **зібраний** `target\release\ryad.exe`, кожен з окремим каталогом даних (`--data`) і штучними файлами в `%TEMP%`. ryad керується тільки повідомленнями у його власні вікна (`WM_COMMAND`, `EM_REPLACESEL`, `WM_CHAR`, `WM_CLOSE`, `TDM_CLICK_BUTTON` для task dialog), без емуляції клавіатури й миші. справжні чернетки (`%LOCALAPPDATA%\ryad`), справжня установка й справжні асоціації не зачіпаються: інсталятор перевіряється в пісочниці `RYAD_TEST_SANDBOX` (файли в теці, реєстр під `HKCU\Software\ryad-test`).

тестові хуки (є в release-збірці, діють тільки зі змінною середовища):

| змінна | що робить |
|---|---|
| `RYAD_DATA` / `--data` | інший каталог даних |
| `RYAD_THEME=light\|dark` | тема без зміни налаштувань windows |
| `RYAD_TEST_FAULT=after-snapshots\|after-index[@n]` | процес виходить (код 91) посеред n-го коміту сесії |
| `RYAD_TEST_SAVE_PATH=<шлях>` | шлях замість системного діалогу «save as»; порожнє значення — «скасовано» |
| `RYAD_TEST_SAVE_FAIL=replace` | останній крок збереження файла відмовляє |
| `RYAD_TEST_SANDBOX=<тека>` | інсталятор і видалення в пісочниці |

## перевірено spike-ом (research/spikes)

поведінка rich edit на цій машині: вірність тексту, одиниці позицій, перенос без втрат undo/виділення/прапорця, «замінити все» одним кроком, ввід кирилиці й surrogate pair через `WM_CHAR`, ліміт тексту, пам'ять кількох вкладок, 1/10/50 мб, довгий рядок, причина повільного завантаження (`IMF_AUTOFONT`). таблиця — architecture.md, розділ 3.

## не перевірено

позначено як невідоме, а не як працююче.

**платформа:**
- **windows 10** — жодного запуску. зокрема: шрифти (segoe ui variable і cascadia mono там немає за замовчуванням — є fallback на segoe ui і consolas), `DWMWA_CAPTION_COLOR` (ігнорується), версія `msftedit.dll`, тема смуг прокрутки;
- 100 % і 200 % масштабу, кілька моніторів з різним dpi, перехід вікна між ними (`WM_DPICHANGED` є в коді, але не викликався);
- висококонтрастна тема (`ui::system_theme` є в коді, не запускалась);
- холодний старт після перезавантаження.

**з реальним вводом** (автоматичні тести не натискають клавіш):
- справжні клавіші з модифікаторами: ctrl+n/o/s/w/tab, alt+z, shift+f3, shift+enter у пошуку, tab між полями панелі. тести s10 надсилають тільки клавіші без модифікаторів (enter, esc, f3): `TranslateAccelerator` читає стан ctrl/shift/alt з клавіатури, а не з повідомлення;
- копіювання тексту з увімкненим переносом у буфер обміну: автоматично не перевіряли, бо копія rich edit потрапила б в історію буфера обміну користувача (win+v); за spike rich edit віддає логічні рядки з crlf;
- **ime** (наприклад, японська розкладка) і перемикання української розкладки під час набору;
- блокування форматних скорочень rich edit (ctrl+b/i/u, ctrl+l/e/r, ctrl+1/2/5): у plain text вони форматували б увесь текст; subclass їх відкидає — перевірити руками;
- drag and drop файлу з провідника на вікно й на текст (`WM_DROPFILES`, `EN_DROPFILES`); між процесами такий дроп не відтворити повідомленнями;
- «відкрити за допомогою → ryad» у провіднику після установки, вибір ryad типовою програмою в налаштуваннях windows, відкриття кількох файлів з провідника одночасно;
- системні діалоги «open» і «save as» (у тестах «save as» підмінено хуком);
- контекстне меню тексту (права кнопка, shift+f10), меню «tabs» і «file › drafts» з клавіатури;
- екранний диктор: rich edit і стандартні кнопки мають ролі, смуга вкладок — ні (обмеження в readme).

**додано ввечері 2026-11-14 — перевірено тільки знімками:**
- смуга меню й темні owner-draw меню: відкриття через alt+f (надісланий `WM_SYSKEYDOWN`) і знімок вікна меню; alt окремо, f10, ←/→ між меню, мнемоніки (`WM_MENUCHAR`) і перемикання мишею автоматично не перевірені;
- вікно інсталятора в обох темах;
- **справжнє видалення блокнота** (`RemovePackageAsync`) і відкриття `ms-settings:defaultapps?registeredAppUser=ryad` не запускались: тести працюють у пісочниці, щоб не чіпати цю машину. руками: установка з перемикачем → блокнота немає в «програмах», відкрилась сторінка ryad у типових програмах; видалення з «bring windows notepad back» → сторінка блокнота в microsoft store;
- предпросмотр у обох темах (заголовки, списки, задачі, цитата з акцентною смужкою, код, таблиця, emoji); перетягування роздільника, синхронна прокрутка й зміна акцентного кольору наживо не перевірені.

**поведінка, яку не відтворено:**
- нестача місця на диску під час збереження файла й під час коміту сесії (код обробляє `ERROR_DISK_FULL` як окрему помилку, сценарій не запускався);
- «exit anyway» з діалогу помилки сесії на виході (шлях є, тест робив помилку тільки під час роботи);
- кінець сеансу windows з незбереженим текстом (`WM_QUERYENDSESSION` записує сесію з очікуванням);
- редагування документа 50 мб з комітами сесії.

## ручний чеклист перед релізом

1. `tools\release.ps1`; запустити `dist\ryad-0.1.0-windows-x64\ryad.exe`.
2. ctrl+n → набрати українською з emoji (ime/розкладкою) → закрити × → відкрити ryad знову: текст, курсор, виділення, прокрутка, активна вкладка.
3. три чернетки і два файли, змінити один файл, «завершити процес» у диспетчері задач посеред набору → відкрити ryad: остання підтверджена копія, файли на диску не змінені.
4. закрити змінену вкладку кожним варіантом; save as → esc; збереження в теку без прав (наприклад `C:\Windows`) → помилка, текст на місці; перезапуск → file › drafts, ctrl+shift+t.
5. відкрити файл, змінити його в notepad, ctrl+s у ryad → конфлікт; «save a copy…» → системний діалог.
6. лог з довгим рядком: alt+z туди й назад, ctrl+c, вставити в notepad, ctrl+s; порівняти байти (fc /b), кінці рядків і bom; пошук і номери рядків з переносом.
7. виділити кілька файлів у провіднику (з пробілами й кирилицею в шляхах) → enter / «відкрити за допомогою»; повторити, поки ryad стартує; у диспетчері задач один ryad.
8. перетягнути файл на вікно і на текст.
9. `dist\ryad-0.1.0-setup.exe` → установка → «відкрити за допомогою» у провіднику; оновлення поверх; windows settings › apps › ryad › uninstall → чернетки лишились; повторна установка піднімає сесію.
10. windows 10 x64: кроки 2–9; 100/150/200 %, перетягування між моніторами; висока контрастність; екранний диктор на тексті й кнопках.
